# mononoki

FibreSight bundles four TTF files so the workbench and saved diagnostics use mononoki across installations. They are mononoki 1.006 by Matthias Tellen, taken from [release 1.6](https://github.com/madmalik/mononoki/releases/download/1.6/mononoki.zip), and distributed under the [SIL Open Font License 1.1](https://github.com/madmalik/mononoki/blob/main/LICENSE).
